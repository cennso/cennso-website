# llms.txt File Format Specification

**Version**: 2.2
**Date**: 2026-11-13 (CENNSO-4534; replaces 1.0 of 2025-11-12; 2.1 drops the sitemap from Optional; 2.2 adds the markdown's Link and the pages' cache policy)
**Based On**: https://llmstxt.org (including its second version's discovery relations)
**Written by**: `scripts/generate-agent-files` after every build; checked by `yarn seo:validate`

## llms.txt

```
# Cennso

> <slogan> <description> Every page below is linked as markdown.

<address>; <email>, <phone>. Customers run Cennso from the cloud portal at <url> (sign-in required).

## Pages

- [Home](https://www.cennso.com/index.md): <meta description>
- [<page name>](https://www.cennso.com/<page>.md): <meta description>

## <name of a page with pages under it>

- [<page name>](https://www.cennso.com/<page>/<child>.md): <meta description>

## Documentation

- [Cennso Documentation](https://docs.cennso.com/llms.txt): <description>

## Optional

- [Full content](https://www.cennso.com/llms-full.txt): every page of this site inline, as markdown
- [Imprint](https://www.cennso.com/imprint.md): <meta description>
- [Privacy Policy](https://www.cennso.com/privacy-policy.md): <meta description>
```

Rules (errors in `yarn seo:validate`):

- One H1, on the first line; a `>` summary right under it.
- Prose only before the first H2. Under an H2, every non-empty line is
  `- [name](url)` or `- [name](url): description`; `[` and `]` in a name are
  written as `(` and `)`.
- Absolute `https://` URLs. Every address on www.cennso.com exists in the build;
  every published page's markdown is linked.
- Every link on www.cennso.com is markdown (a page's `.md` or `llms-full.txt`):
  afdocs' `llms-txt-links-markdown` fails under 90%. The sitemap is named in
  `robots.txt`, not here.
- Under 50 000 characters. No generation date, no version.
- Pages are the HTML the build rendered (the sitemap's list): a page switched
  off with `notFound` is not listed.

## llms-full.txt

The same H1, summary and paragraph, then for every page (legal pages last):

```
## <page name>

Source: <page address>

<the page's markdown, its headings two levels down>
```

## A page's markdown (`/<page>.md`, `/index.md` for the home page)

```
> For AI agents: an index of this site is at https://www.cennso.com/llms.txt, and every page is also available as markdown at its own address with .md appended.

<the page's main content, converted from its rendered HTML>

Source: <page address>
```

Converted from the rendered `<main>`: navigation, scripts, artwork without a
description, controls and the HTML's own sentence for agents left out; addresses
made absolute; an image drawn once per theme listed once.

## Serving

- `llms.txt`, `llms-full.txt`, `*.md`: `text/markdown; charset=utf-8`,
  `X-Robots-Tag: noindex`.
- A page's markdown (`/<page>.md`): `Link: <https://www.cennso.com/<page>>; rel="canonical", </llms.txt>; rel="describedby"`:
  the HTML is the page a search engine lists.
- Every page: `Link: </<page>.md>; rel="alternate"; type="text/markdown", </llms.txt>; rel="describedby"`,
  `Vary: Accept`; with `Accept: text/markdown` the page's address answers its
  markdown (`next.config.js` rewrites).
- Every page: `Cache-Control: public, max-age=0, must-revalidate`. On Vercel
  the HTML's `Vary` is the one `@vercel/next` writes for every prerender,
  without `Accept`; Vercel's edge caches after the rewrite and keeps both
  answers apart, so no other shared cache may keep a page.
